# Assets Directory

Place your images here:

1. **logo.png** - Eduflow logo image
   - Should show "Edu" in grey (#B3B3B3) and "flow" in purple (#51287E)
   - Recommended size: 180px x 45px

2. **Dashboard.jpg** - Dashboard preview image
   - Screenshot/preview of the dashboard
   - Recommended size: 392px x 255px (or similar aspect ratio)

The landing page will automatically use these images if they exist in this directory.
